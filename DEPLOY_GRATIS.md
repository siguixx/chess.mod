# Publicar CHESS.MOD Gratis en Internet ($0 — Sin PowerShell, PC y Celular)

Sigue estos **6 pasos sencillos** (3–5 minutos) para obtener tu enlace público gratuito **`https://chessmod.onrender.com`** con **Multijugador Online Real**, **Elo desde 0**, **Base de Datos permanente**, **soporte para PC y Celular** y acceso al **Boss Secreto** en `/blacky`:

---

### Paso 1 — Crea tu base de datos PostgreSQL gratuita ($0)
1. Entra a **[neon.tech](https://neon.tech)** (o **[supabase.com](https://supabase.com)**) y crea una cuenta gratuita.
2. Crea un proyecto nuevo (Plan Free, $0).
3. Copia tu cadena de conexión **`DATABASE_URL`** (empieza por `postgres://...` o `postgresql://...`).

### Paso 2 — Sube esta carpeta a GitHub (Gratis)
1. Entra a **[github.com/new](https://github.com/new)** y crea un repositorio llamado **`chessmod`**.
2. Sube el contenido de esta carpeta `chess-mod` al repositorio (puedes arrastrar los archivos en GitHub o usar `git init && git add . && git commit -m "CHESS.MOD" && git push`).

### Paso 3 — Conecta GitHub con Render.com ($0 Free Tier)
1. Entra a **[render.com](https://render.com)** e inicia sesión con tu cuenta de GitHub.
2. Haz clic en **New + → Blueprint** y selecciona tu repositorio **`chessmod`**.
3. Render detectará automáticamente el archivo **`render.yaml`** con el nombre **`chessmod`** (sin marca de agua, HTTPS/WSS automático y chequeo `/health`).

### Paso 4 — Pega tu `DATABASE_URL`
1. Cuando Render te pida la variable **`DATABASE_URL`**, pega el enlace PostgreSQL que copiaste en el Paso 1.
2. Haz clic en **Apply / Deploy**.

### Paso 5 — Abre tu enlace público en PC y Celular
En 2 minutos Render te entregará tu URL pública permanente (por ejemplo):
- **Juego principal y Multijugador Online**: `https://chessmod.onrender.com`
- **Boss Secreto (BLACKY · Imposible)**: `https://chessmod.onrender.com/blacky` *(o `/?boss=blacky` / `#blacky`)*

### Paso 6 — ¡Juega con quien quieras sin PowerShell!
- Cualquier amigo en **PC o celular** solo abre el enlace en Chrome/Safari/Edge, se registra (empieza en **0 Elo**) y entra a **Multijugador** para jugar contra ti en tiempo real con relojes sincronizados y Ranking Global permanente.
